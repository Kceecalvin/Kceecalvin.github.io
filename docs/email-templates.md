## Zoho Mail Configuration Notes

### Auto-Reply Setup
1. Go to Zoho Mail → Settings → Auto-Reply
2. Set the auto-reply for `cal-dev@zohomail.com`
3. Use Template #1 above as the auto-reply body
4. Set active hours: Always on (or business hours 8AM-8PM EAT)
